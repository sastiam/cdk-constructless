# Security Policy

## Supported versions

Only the latest release receives security fixes while the project is pre-1.0.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: [Report a vulnerability](https://github.com/sastiam/cdk-constructless/security/advisories/new).

Include a description, affected versions, and steps to reproduce. You can expect an initial response within 7 days.

## Scope

This library only synthesizes CloudFormation templates. Reports about overly permissive IAM policies, insecure defaults, or secrets accidentally committed to the repository are in scope.
