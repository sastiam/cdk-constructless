# BudgetActionExecutionRole

## Purpose

A Budget Action runs with an IAM role that AWS Budgets assumes when a budget threshold is crossed. A hand-written role is easy to get wrong: it can miss the confused-deputy conditions, so another account's budget could assume it, or it can grant more than the action needs. This construct creates that role with the trust conditions that AWS documents, and it grants only the permissions needed to stop one instance type through SSM automation. The role does not start anything and does not create the Budget Action itself.

## Resources created

| CloudFormation type | Count | Notes |
| --- | --- | --- |
| `AWS::IAM::Role` | 1 | Always created. Its trust policy allows `sts:AssumeRole` to `budgets.amazonaws.com` only when `aws:SourceAccount` is the stack account and `aws:SourceArn` matches `arn:<partition>:budgets::<account>:budget/*`. The role has no managed policies attached. |
| `AWS::IAM::Policy` | 1 | The inline `DefaultPolicy` that holds the stop statements. CDK creates it on the first `allowStopInstances` call, so it is absent when no target is allowed. Each target adds its statements once. |

## Props and defaults

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `roleName` | `string` | a name generated by CDK | The physical name of the IAM role. Leave it unset to let CDK generate a unique name. |

The construct has one method, `allowStopInstances(target: StopInstancesTarget): void`. It is not a prop. It grants the permissions in the table below for one target. Calling it again for the same target adds nothing.

`StopInstancesTarget` has two members: `EC2` (value `'EC2'`) and `RDS` (value `'RDS'`).

### Permissions per `StopInstancesTarget`

| Target | SSM document | Statement | Actions | Resources | Condition |
| --- | --- | --- | --- | --- | --- |
| `EC2` | `AWS-StopEC2Instance` | Stop | `ec2:DescribeInstanceStatus`, `ec2:StopInstances` | `*` | `ForAnyValue:StringEquals` `aws:CalledVia` `ssm.amazonaws.com` |
| `EC2` | `AWS-StopEC2Instance` | Run automation | `ssm:StartAutomationExecution` | `document/AWS-StopEC2Instance`, `automation-execution/*`, `automation-definition/AWS-StopEC2Instance:*` | none |
| `RDS` | `AWS-StopRdsInstance` | Stop | `rds:DescribeDBInstances`, `rds:StopDBInstance` | `*` | `ForAnyValue:StringEquals` `aws:CalledVia` `ssm.amazonaws.com` |
| `RDS` | `AWS-StopRdsInstance` | Run automation | `ssm:StartAutomationExecution` | `document/AWS-StopRdsInstance`, `automation-execution/*`, `automation-definition/AWS-StopRdsInstance:*` | none |

The SSM resources are ARNs of the form `arn:<partition>:ssm:*:*:<resource>`, where `<partition>` is the stack's partition. The `ec2:` and `rds:` stop actions are granted only when the call comes through SSM. No `ec2:StartInstances` or `rds:StartDBInstance` action is ever granted.

## Cost impact

**None** from the construct's own resources: it creates one `AWS::IAM::Role` and one `AWS::IAM::Policy`, and no fixed-cost resource. The IAM price is not recorded in [`../aws-facts.md`](../aws-facts.md) yet, so this page gives no USD figure.

## Verified AWS facts

- The trust policy uses `budgets.amazonaws.com` with `aws:SourceAccount` and `aws:SourceArn` as in the AWS example policies. See [`../aws-facts.md`](../aws-facts.md).
- The AWS managed policy `AWSBudgetsActions_RolePolicyForResourceAdministrationWithSSM` grants EC2 and RDS stop through `ssm.amazonaws.com` and `ssm:StartAutomationExecution` on the `AWS-Stop*` documents (updated 2026-04-07). This construct grants the stop part of that policy only. See [`../aws-facts.md`](../aws-facts.md).

## Limits and risks

- **Stop only.** The AWS managed policy also grants Start actions. This construct deliberately does not grant them, so a Budget Action that uses this role can stop instances and RDS databases but cannot start them again. Restarting needs permissions that this role does not hold.
- **Stop permissions only for the targets you allow.** The role receives no stop permission until `allowStopInstances` is called. Allow only the targets your Budget Action needs.
- **Trust scope.** `aws:SourceArn` matches every budget in the account (`budget/*`), not one named budget. Any budget in the stack's account can be configured to run its Budget Action with this role.
- **Future SCP permissions.** Service control policy (SCP) permissions tracked in #71 will extend this role in a later change. Until then, the role holds only the stop permissions described above.
- **cdk-nag suppressions.** The stop statements use wildcard resources, so `AwsSolutions-IAM5` reports one finding per wildcard resource on the role's default policy. Each target's `allowStopInstances` call acknowledges its findings with `suppressNag` and the reason `Budget Actions stop instances through SSM automation documents; AWS documents these wildcard resources`. The finding ids are:
  - `AwsSolutions-IAM5[Resource::*]` (both targets)
  - `AwsSolutions-IAM5[Resource::arn:<AWS::Partition>:ssm:*:*:document/AWS-StopEC2Instance]` (`EC2`)
  - `AwsSolutions-IAM5[Resource::arn:<AWS::Partition>:ssm:*:*:automation-execution/*]` (both targets)
  - `AwsSolutions-IAM5[Resource::arn:<AWS::Partition>:ssm:*:*:automation-definition/AWS-StopEC2Instance:*]` (`EC2`)
  - `AwsSolutions-IAM5[Resource::arn:<AWS::Partition>:ssm:*:*:document/AWS-StopRdsInstance]` (`RDS`)
  - `AwsSolutions-IAM5[Resource::arn:<AWS::Partition>:ssm:*:*:automation-definition/AWS-StopRdsInstance:*]` (`RDS`)

  The stop actions cannot be scoped to instance ARNs through SSM automation without per-instance policies, which this construct does not create.

## Example

```typescript
import { App, Stack } from 'aws-cdk-lib';
import { BudgetActionExecutionRole, StopInstancesTarget } from 'cdk-constructless';

const app = new App();
const stack = new Stack(app, 'Example', {
  env: { account: '123456789012', region: 'eu-west-1' },
});

// Role that AWS Budgets assumes to stop EC2 and RDS instances through SSM.
const executionRole = new BudgetActionExecutionRole(stack, 'BudgetActionExecutionRole');
executionRole.allowStopInstances(StopInstancesTarget.EC2);
executionRole.allowStopInstances(StopInstancesTarget.RDS);
```
