# BudgetScpAction

## Purpose

In an AWS Organization, the strongest automatic cut-off for a member account is a deny service control policy (SCP) attached to that account. A Budget Action that attaches the SCP runs when the budget threshold is crossed, so the member account can no longer create or start the denied compute actions, whatever IAM policies its users hold. This construct creates the deny SCP unattached and a Budget Action on a [`CostBudget`](CostBudget.md) that attaches it to the account, organizational unit or root IDs you list. The SCP does not stop resources that already run, so pair this construct with [BudgetStopInstancesAction](BudgetStopInstancesAction.md) to stop existing instances. This construct works only from the management account of the organization.

## Resources created

| CloudFormation type | Count | Notes |
| --- | --- | --- |
| `AWS::Organizations::Policy` | 1 | Always created as `Policy`. Its type is `SERVICE_CONTROL_POLICY`, and it has one `Deny` statement (`Sid` `BudgetDenyCompute`) over the `deniedActions` list on `*`. It has no `TargetIds`, so it is not attached until the Budget Action runs. It is retained on stack deletion. |
| `AWS::Budgets::BudgetsAction` | 1 | Always created as `Action`. `ActionType` is `APPLY_SCP_POLICY`. The action depends on the wrapped budget. |
| `AWS::IAM::Role` | 1 | Created only when `executionRole` is not passed, as the child `ExecutionRole`. It is a [BudgetActionExecutionRole](BudgetActionExecutionRole.md). Count is 0 when `executionRole` is passed. |
| `AWS::IAM::Policy` | 1 | Created only when `executionRole` is not passed, as the role's `DefaultPolicy` that holds the `organizations:AttachPolicy`, `organizations:DetachPolicy` and `organizations:DescribePolicy` statement. When `executionRole` is passed, the statement is added to that role's own policy, and this construct creates no policy. |

## Props and defaults

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `budget` | `CostBudget` | none (required) | The budget whose threshold runs the action. The action depends on this budget and uses its name. |
| `targetIds` | `string[]` | none (required) | The account IDs, organizational unit IDs or root IDs that the SCP is attached to when the action runs. Between 1 and 100 items. An account ID is 12 digits, an OU ID starts with `ou-` and a root ID starts with `r-`. |
| `threshold` | `number` | `80` | The threshold that runs the action. A percentage from 0.01 to 1000 when `thresholdType` is `PERCENTAGE`; an amount greater than 0 when `thresholdType` is `ABSOLUTE_VALUE`. |
| `thresholdType` | `BudgetActionThresholdType` | `BudgetActionThresholdType.PERCENTAGE` | How `threshold` is measured. |
| `notificationType` | `BudgetNotificationType` | `BudgetNotificationType.ACTUAL` | Whether the threshold is compared against actual or forecasted spend. |
| `approvalModel` | `BudgetActionApprovalModel` | `BudgetActionApprovalModel.AUTOMATIC` | Whether the action runs automatically or waits for approval. The default runs an unattended lab account without a person in the loop. |
| `deniedActions` | `string[]` | `DEFAULT_DENIED_COMPUTE_ACTIONS` (`ec2:RunInstances`, `ec2:StartInstances`, `lambda:CreateFunction`, `ecs:CreateService`, `ecs:RunTask`, `rds:CreateDBInstance`, `rds:StartDBInstance`) | The IAM actions that the SCP denies on all resources. Each entry must look like `service:Action`, for example `sagemaker:CreateEndpoint`. The list replaces the defaults, so include the defaults you still need. The SCP document must not exceed 5120 characters. |
| `policyName` | `string` | a name generated by CDK (`Names.uniqueResourceName`, at most 128 characters) | The physical name of the service control policy. Leave it unset to let CDK generate a unique name. |
| `subscribers` | `BudgetActionSubscriber[]` | none (required) | The recipients of the action notifications. Between 1 and 11 items. |
| `executionRole` | `BudgetActionExecutionRole` | a new `BudgetActionExecutionRole` created as the child `ExecutionRole` of this construct | The role that AWS Budgets assumes to attach the SCP. When it is set, the construct grants it the attach, detach and describe permissions for SCPs. |

`DEFAULT_DENIED_COMPUTE_ACTIONS` is exported as a constant. The shared types `BudgetActionThresholdType`, `BudgetActionApprovalModel` and `BudgetActionSubscriber` are the same ones that [BudgetDenyAction](BudgetDenyAction.md) uses. `BudgetActionSubscriber` sets exactly one of `email` or `topic`.

## Cost impact

**Fixed**, for the Budget Action only. The construct's own resources cost nothing: an SCP and an IAM role have no charge, so the construct creates no fixed-cost resource. The charge comes from AWS Budgets for an action-enabled budget. The first two action-enabled budgets per account are free each month; each additional one costs 0.10 USD per day, whatever the usage. See [`../aws-facts.md`](../aws-facts.md).

## Verified AWS facts

- Only a management account can apply SCPs through Budget Actions, so this construct must be deployed in the management account. See [`../aws-facts.md`](../aws-facts.md).
- `AWS::Budgets::BudgetsAction` requires `ActionThreshold`, `ActionType`, `BudgetName`, `Definition`, `ExecutionRoleArn`, `NotificationType` and `Subscribers`. The construct sets all of them. See [`../aws-facts.md`](../aws-facts.md).
- A reverted Budget Action is not evaluated again in the same budget period unless it is reset. See [`../aws-facts.md`](../aws-facts.md).
- Unconfirmed: whether Budget Actions are available on the AWS Free Plan. See [`../aws-facts.md`](../aws-facts.md).
- The first two action-enabled budgets per account are free each month; each additional one costs 0.10 USD per day. See [`../aws-facts.md`](../aws-facts.md).
- The execution role's trust policy uses `budgets.amazonaws.com` with `aws:SourceAccount` and `aws:SourceArn`. See [BudgetActionExecutionRole](BudgetActionExecutionRole.md) and [`../aws-facts.md`](../aws-facts.md).
- Assumption (verify on the Organizations quotas page): the maximum SCP document size is 5,120 characters. The construct enforces this limit at synth time. See [`../aws-facts.md`](../aws-facts.md).
- Budgets data refreshes up to three times a day, 8 to 12 hours apart. See [`../aws-facts.md`](../aws-facts.md).

## Limits and risks

- **Management account only.** Deploy the stack that contains this construct in the management account of the organization. Only a management account can apply SCPs through Budget Actions. The construct does not check the account at synth time.
- **Reverting and reset.** Reverting is a manual step. In the Budgets console, a completed action can be undone from the Action history table. A reversed action is marked as reversed, and AWS Budgets does not evaluate it again for the rest of the budget period unless you choose Reset. This construct provides no revert or reset: it does not run either step, and it does not schedule one. The Budgets pages that this page cites do not say whether reverting an SCP action detaches the SCP from `targetIds`. Test the revert in a sandbox organization before you rely on it to lift the deny policy.
- **Existing resources keep billing.** The SCP blocks only creating and starting the denied actions. Running EC2 instances, RDS databases, Lambda functions, and ECS services and tasks keep running and keep billing. Pair this construct with [BudgetStopInstancesAction](BudgetStopInstancesAction.md) to stop the instances you list.
- **The management account and service-linked roles are not affected.** SCPs do not affect the management account or service-linked roles, so the denied actions do not stop them. This is an AWS Organizations behavior and is not recorded in [`../aws-facts.md`](../aws-facts.md) yet.
- **Only the listed targets are denied.** The SCP applies only to the account, OU or root IDs in `targetIds`. Other accounts keep their permissions. Construction fails with `targetIds must contain between 1 and 100 items, got <count>` when `targetIds` is empty or has more than 100 items.
- **Target ID shape.** Construction fails with `targetIds entries must be account, OU or root IDs, got "<value>"` for the first target that is not a 12-digit account ID, an `ou-` OU ID or an `r-` root ID.
- **Only the listed actions are denied.** The default list covers the compute actions named above. Other compute actions, for example `sagemaker:CreateEndpoint`, are denied only when you add them to `deniedActions`. The list replaces the defaults, so a custom list must include each default you still need.
- **Denied action shape.** Construction fails with `deniedActions entries must look like service:Action, got "<value>"` for the first entry that does not match `/^[a-z0-9-]+:[A-Za-z0-9*]+$/`.
- **SCP size limit.** Construction fails with `SCP document is <n> characters; the limit is 5120` when the SCP document is longer than 5120 characters. The length is checked at synth time only when no denied action is an unresolved token. The 5120 limit is an assumption to verify on the Organizations quotas page. See [`../aws-facts.md`](../aws-facts.md).
- **Retained policy.** The SCP is retained on stack deletion (`RemovalPolicy.RETAIN`), so an SCP that is attached during an incident is never deleted with the stack. The consequence is that a retained SCP stays in the organization after the stack is deleted, and you must remove it yourself.
- **Budgets data lag.** Budgets data lags 8 to 12 hours, so the action can run long after the spend occurred. See [`../aws-facts.md`](../aws-facts.md).
- **Automatic approval by default.** `approvalModel` defaults to `AUTOMATIC`, so the SCP is attached without a person approving it. Set `MANUAL` to wait for an approval first.
- **Execution role reach.** `allowApplyScpPolicy` grants `organizations:AttachPolicy`, `organizations:DetachPolicy` and `organizations:DescribePolicy` on `*`. The role can therefore attach and detach any SCP in the organization to any target, not only the SCP of this construct. The construct cannot narrow the grant, because the targets are known only when the action runs. See [BudgetActionExecutionRole](BudgetActionExecutionRole.md).
- **cdk-nag.** The construct adds no suppression of its own, and the SCP has no finding in the validation report. The execution role acknowledges its own wildcard finding `AwsSolutions-IAM5[Resource::*]` on the role's default policy, with the reason `SCP attach targets are only known at action time`, in `allowApplyScpPolicy`. See [BudgetActionExecutionRole](BudgetActionExecutionRole.md).

## Example

```typescript
import { App, Stack } from 'aws-cdk-lib';
import { BudgetScpAction, CostBudget } from 'cdk-constructless';

const app = new App();
const stack = new Stack(app, 'Example', {
  env: { account: '123456789012', region: 'eu-west-1' },
});

const budget = new CostBudget(stack, 'MonthlyBudget', {
  limitUsd: 5,
  emails: ['alerts@example.com'],
});

// Deploy this stack in the management account. Attach the deny SCP to a member account when actual spend reaches 80 percent of the budget.
new BudgetScpAction(stack, 'DenyComputeScp', {
  budget,
  targetIds: ['123456789012'],
  subscribers: [{ email: 'alerts@example.com' }],
});
```
