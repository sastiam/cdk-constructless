# CostBudget

## Purpose

A monthly USD budget tells you when your spend crosses a limit you chose, so you learn about an unexpected bill while you can still act on it. Budgets are alerts, not a hard cap: AWS Budgets refreshes its data only up to three times a day, and this construct does not stop spending. To act on spend automatically, attach Budget Actions to the wrapped `budget`; this construct does not create them.

## Resources created

| CloudFormation type | Count | Notes |
| --- | --- | --- |
| `AWS::Budgets::Budget` | 1 | Always one budget with `BudgetType` `COST`, `TimeUnit` `MONTHLY` and `BudgetLimit` `{ Amount: limitUsd, Unit: 'USD' }`. Notifications are attached only when `emails` or `topic` is given. No other resource is created. |

## Props and defaults

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `limitUsd` | `number` | none (required) | The monthly budget limit in USD. Must be greater than 0. |
| `budgetName` | `string` | a name generated by CDK (`Names.uniqueResourceName`, at most 100 characters) | The physical name of the budget. Leave it unset to let CDK generate a unique name. |
| `thresholds` | `BudgetThreshold[]` | `ACTUAL 60`, `ACTUAL 80`, `ACTUAL 100`, `FORECASTED 100` (`DEFAULT_BUDGET_THRESHOLDS`) | The thresholds that trigger a notification. Between 1 and 5 items; each `percent` must be between 0.01 and 1000. Notifications are created only when `emails` or `topic` is given. |
| `emails` | `string[]` | `[]` (no e-mail subscribers) | The e-mail addresses that receive every notification. Between 0 and 10 items. |
| `topic` | `sns.ITopic` | none (no SNS subscriber) | The SNS topic that receives every notification. The topic policy must allow AWS Budgets to publish. |
| `linkedAccountIds` | `string[]` | none (the budget covers all linked accounts) | The 12-digit account IDs whose costs this budget covers. Between 1 and 100 items. Use it from the management account to budget one member account. |

Each `BudgetThreshold` has a `percent` (required, from 0.01 to 1000) and an optional `type`, a `BudgetNotificationType`: `ACTUAL` (default) compares actual spend and `FORECASTED` compares forecasted spend.

## Cost impact

**None** from the construct's own resources: it creates one `AWS::Budgets::Budget` and no fixed-cost resource. The AWS Budgets price is not recorded in [`../aws-facts.md`](../aws-facts.md) yet, so this page gives no USD figure.

## Verified AWS facts

- Budgets data refreshes up to three times a day, 8 to 12 hours apart. See [`../aws-facts.md`](../aws-facts.md).
- `BudgetData` `CostFilters` supports a `LinkedAccount` filter, used by `linkedAccountIds`. See [`../aws-facts.md`](../aws-facts.md).
- Assumption, to verify before 1.0: a budget supports at most 5 notifications and 10 e-mail subscribers per notification. See [`../aws-facts.md`](../aws-facts.md).

## Limits and risks

- **Not a hard cap.** Budgets data refreshes up to three times a day, 8 to 12 hours apart, so spend can pass `limitUsd` before a notification is sent. Attach Budget Actions to the wrapped `budget` to act on spend.
- **At most 5 thresholds.** `thresholds` must contain between 1 and 5 items, otherwise construction fails with `thresholds must contain between 1 and 5 items, got <n>`. The default produces 4 notifications.
- **At most 10 e-mail addresses.** `emails` must contain between 0 and 10 items, otherwise construction fails with `emails must contain between 0 and 10 items, got <n>`. The limit of 5 notifications and 10 subscribers per notification is an assumption to verify before 1.0 (see Verified AWS facts).
- **Threshold range.** Each `percent` must be between 0.01 and 1000, otherwise construction fails with `thresholds[<i>].percent must be between 0.01 and 1000, got <value>`.
- **Member-account IDs.** `linkedAccountIds` must contain between 1 and 100 items, each a 12-digit account ID, otherwise construction fails with `linkedAccountIds must be 12-digit account IDs, got "<id>"`.
- **No subscribers, no alert.** Without `emails` or `topic`, no notification is created and the warning `cdk-constructless:budget-without-subscribers` is emitted.
- **Topic policy.** The SNS topic given in `topic` must allow AWS Budgets to publish; this construct does not change the topic policy.
- **cdk-nag.** This construct adds no `suppressNag` entries and has no deliberate findings.

## Example

```typescript
import { App, Stack } from 'aws-cdk-lib';
import { CostBudget } from 'cdk-constructless';

const app = new App();
const stack = new Stack(app, 'Example', {
  env: { account: '123456789012', region: 'eu-west-1' },
});

// Monthly 5 USD budget with the default thresholds, e-mailed to one address.
new CostBudget(stack, 'MonthlyBudget', {
  limitUsd: 5,
  emails: ['alerts@example.com'],
});

// First-charge alert: notify as soon as actual spend reaches 0.01 USD.
new CostBudget(stack, 'FirstChargeBudget', {
  limitUsd: 0.01,
  thresholds: [{ percent: 100 }],
  emails: ['alerts@example.com'],
});

// Budget for one member account, created in the management account.
new CostBudget(stack, 'MemberAccountBudget', {
  limitUsd: 5,
  linkedAccountIds: ['123456789012'],
  emails: ['alerts@example.com'],
});
```
